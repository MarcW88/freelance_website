# Comparison workflow references

These files are optional working aids for `comparison-content-workflow`.

- `comparison-brief-template.md` — per-page decision brief.
- `comparison-data-template.yaml` — method-neutral evidence/recommendation record.
- `comparison-publish-gate-template.md` — final PUBLISH_REVIEW checklist.

None of these templates requires scoring, weighting, fixed heading counts, word counts or link quotas. A page should only use fields/components that improve its actual decision.
