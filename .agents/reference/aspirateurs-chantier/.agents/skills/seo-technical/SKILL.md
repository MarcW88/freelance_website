# Technical SEO

Check the layer beneath content.

## Core layers
1. Crawlability: robots, status codes, sitemap, crawl traps.
2. Indexability: robots meta, canonical consistency, duplicate signals.
3. Rendering: important content available in rendered HTML and no accidental bot/user divergence.
4. Architecture: internal reachability, breadcrumbs, orphan pages, redirects and broken links.
5. Structured data: markup reflects visible content and real evidence; no fake review/test/rating claims.
6. Page experience: mobile usability, stable layout, HTTPS and major performance blockers.

Always detect the project stack before applying framework-specific advice. Mark non-applicable checks N/A rather than forcing them.

Never estimate missing measurements. State the data gap and which conclusions it limits.
