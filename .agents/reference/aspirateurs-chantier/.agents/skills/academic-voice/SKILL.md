# Academic Voice

Use only when the genre genuinely calls for analytical or research-style exposition.

Develop an argument for an intelligent reader; distinguish evidence, interpretation and conjecture; name actual relations instead of managerial metaphors; preserve uncertainty; and let emphasis follow intellectual priority rather than symmetrical structure.

Do not mistake abstraction, nominalization or passive voice for rigor. Keep necessary technical terminology but remove corporate, social-media and repository/changelog register from finished exposition.

When embedded, return only the revised prose or requested findings and do not invoke the wider writing pipeline recursively.
