# Editorial QA

Use last. Do not rewrite the whole page automatically when a gate fails.

## Gates
1. Intent: one clear primary role; answer/decision help appears early enough; irrelevant sections removed.
2. Original value: more useful than manufacturer/merchant copy; recommendations have criteria and limitations; no fake hands-on.
3. Factuality: material facts verified; uncertainty qualified; comparisons traceable to evidence or clearly editorial.
4. Natural writing: no conspicuous generic/template patterns, mechanical rhythm, promotional smoothing or empty intro/conclusion.
5. SEO preservation: title/H1/topic coherent; links logical; no new cannibalization or stuffing; technical signals consistent.
6. User usefulness: the page still helps if affiliate links disappear and enables a better next decision.

## Output
PASS: status, three strongest qualities/improvements, remaining minor risks.
FAIL: failing gates, concrete blockers, and the skill/workflow to return to.

A FAIL does not automatically justify a full rewrite.
