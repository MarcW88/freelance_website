# Affiliate Value

## Core rule
The page must remain useful if every affiliate link is removed. Rewording a manufacturer or merchant description is not original value.

## Evidence levels
- A: verified primary specification/documentation.
- B: reliable distributor/retailer information, checked against primary sources when possible.
- C: patterns from multiple credible user sources, presented as user experience.
- D: real first-hand test only when documented test data, notes, photos or measurements exist.

Without D, never claim first-hand testing or observation.

## Decision value
Where relevant, explain who the option suits, who it does not suit, decisive benefits and limitations, meaningful alternatives, compatibility constraints, total cost, and which apparently important specifications actually change the decision.

Set comparison criteria before choosing a winner. Do not rank by commission, hide disadvantages, present temporary prices as permanent, or call something “best” without explicit criteria.

## Output
1. Unique value already present
2. Merchant-like content to remove
3. Missing decision information
4. Evidence needed
5. Claims to qualify
6. Recommended comparison criteria
