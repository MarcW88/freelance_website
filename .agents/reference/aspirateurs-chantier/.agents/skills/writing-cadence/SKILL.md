# Writing Cadence

Shape rhythm around meaning and emphasis, not a target pattern of short and long sentences.

At paragraph scale, flag repeated openings, repeated sentence skeletons, runs of very short sentences, long sentences carrying several independent inferences, abstract process framing that hides the actor, repeated contrast templates, and paragraph endings that merely recap or add a slogan.

Join sentences when one provides the other's cause, condition, contrast or consequence. Split when a sentence changes subjects repeatedly or carries separate main claims. Keep a meaningful negative result or technical contrast even if its syntax resembles a common pattern.

Read at speaking pace and restore any technical distinction or deliberate cadence lost during restructuring.

When embedded, return only revised prose or cadence findings.
