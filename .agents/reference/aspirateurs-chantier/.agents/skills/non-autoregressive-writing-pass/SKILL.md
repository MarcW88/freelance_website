# Non-Autoregressive Writing Pass

Run only after claims, evidence and broad structure are stable.

Read the complete artifact first. Extract title, headings, paragraph heads and paragraph endings. Judge each against what the full section or paragraph eventually establishes, not merely against the previous sentence.

Revise generic openings, headings that promise the wrong subject, repeated restart phrases, vague pointers, rejected-alternative-first openings, and boundaries that overstate causal or evidential relations.

A paragraph ending should complete its own reasoning before serving as a transition. Do not add recap sentences merely to make a paragraph feel finished.

After revision, read the full artifact again and confirm that no fact, uncertainty, evidence level or scope changed.
