# Better Usage

A sentence can be grammatical and still express the wrong relation.

Identify subject, verb and object/complement; paraphrase the intended relation without the suspect verb; then confirm that the subject can literally perform the action and that the object fits the relation.

Name a missing intermediate only when it represents a real property, actor, condition, interpretation or consequence. Do not add abstract nouns merely to sound precise.

Preserve conventional technical shorthand when clear, but recast it when it hides a distinction that matters. Recheck epistemic force after every repair: support must not become proof, correlation must not become explanation, and documentation must not become observed experience.

When invoked by another writing skill, return only the revised prose or usage findings.
