# General Writing

Run `humanizer` first in embedded mode, then apply this house-style pass.

## Principles
- Make the minimum effective edit.
- Lead with the point when setup adds nothing.
- Preserve specific facts, uncertainty and recognizable voice.
- Prefer concrete subjects and direct verbs.
- Remove ornamental binary contrasts, faux-insight setups, vague authority, slogan endings, repetitive transitions and decorative formatting.
- Avoid synonym cycling: repeat the clear technical term when it is the correct term.
- Keep lists for real sets, procedures or scan tasks; use prose when the items form an argument.
- Do not manufacture a conclusion if the last substantive sentence already finishes the reasoning.
- Never add facts during a style pass.

Review title, headings, callout labels and body prose as writing. A heading should name the real subject or reader task, not a generic category.

When embedded, return only the revised artifact or requested findings.
