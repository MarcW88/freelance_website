# Internal Linking Rules

Use these rules to evaluate recommendations:

1. Map topic clusters before placing links.
2. Keep pillar pages, cluster pages, and supporting pages connected bidirectionally when useful.
3. Prefer contextual body links over navigation/footer links for SEO relevance.
4. Use descriptive, partial-match, natural anchor text.
5. Avoid duplicate exact-match anchors to the same target.
6. Do not add a link unless it helps the reader at that point in the page.
7. Keep strategic pages within three clicks where crawl graph data is available.
8. Re-audit quarterly or after major content/category migrations.

A target URL existing in global navigation does not mean the contextual link opportunity is solved. A target URL already present in body copy usually means no action is needed unless the anchor is generic or contextually weak.
